A strong chess engine in 4 KB of Python: tapered PeSTO evaluation, PVS search with null-move pruning and late-move reductions, a transposition table, quiescence search, and repetition handling, searching to a fixed 200,000-node cap per move. Local practice mean Elo 1,706.

## Run it

```sh
python3 main.py
```
